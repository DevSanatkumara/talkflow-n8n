# Интеграция потокового чтения с n8n webhook

## Обзор реализации

Клиент теперь поддерживает потоковое чтение ответов от n8n webhook в формате NDJSON (Newline Delimited JSON).

## Формат n8n потока

n8n отправляет события в следующем формате:

```json
{"type":"begin","metadata":{"nodeId":"...","nodeName":"AI Agent","itemIndex":0,"runIndex":0,"timestamp":1756034804924}}
{"type":"item","content":"Часть текста","metadata":{...}}
{"type":"item","content":" продолжение","metadata":{...}}
{"type":"end","metadata":{"nodeId":"...","nodeName":"AI Agent","itemIndex":0,"runIndex":0,"timestamp":1756034834054}}
```

## Реализованные компоненты

### 1. `src/utils/streamReader.ts` - Утилита потокового чтения
- **readN8nStream()** - основная функция для чтения NDJSON потока
- **readN8nStreamSimple()** - упрощенная версия с колбэком обновления
- Обработка событий: `begin`, `item`, `end`
- Накопление контента из `item` событий
- Обработка ошибок парсинга

### 2. `src/hooks/useMessageSender.ts` - Модифицированный хук отправки
- Использует `readN8nStreamSimple()` вместо `response.text()`
- Создает сообщение с флагом `isStreaming: true`
- Обновляет контент в реальном времени через колбэк
- Fallback на обычное чтение при ошибках потока
- Убирает флаг `isStreaming` по завершении

### 3. `src/types/chat.ts` - Обновленные типы
- Добавлено поле `isStreaming?: boolean` в интерфейс `Message`

### 4. `src/components/ChatMessage.tsx` - UI для потокового вывода
- Показывает индикатор "печатает..." во время потока
- Скрывает кнопку "Копировать" во время потока
- Анимированный спиннер с текстом

### 5. `src/components/chat/ChatMessages.tsx` - Умный автоскролл
- Дебаунсинг скролла для потоковых сообщений (100мс)
- Плавный скролл для обычных сообщений
- Определение потоковых сообщений через `isStreaming` флаг

## Тестирование

### 1. Проверьте настройку webhook URL
В `.env` или `public/env-config.js` должен быть правильный URL:
```javascript
VITE_N8N_WEBHOOK_URL: "https://avatarsswami.app.n8n.cloud/webhook-test/025e2071-c8ee-4845-b02d-d2a36e20ec1f"
```

### 2. Запустите приложение
```bash
npm run dev
# или
yarn dev
```

### 3. Проверьте потоковый режим
1. Отправьте сообщение в чат
2. Должно появиться пустое сообщение ассистента
3. Рядом с временем появится "печатает..." с анимацией
4. Текст должен появляться частями в реальном времени
5. По завершении индикатор исчезнет и появится кнопка "Копировать"

### 4. Отладка
Откройте DevTools и посмотрите в консоль:
- `n8n stream начался:` - событие begin
- `Получена часть контента:` - события item
- `n8n stream завершился:` - событие end

### 5. Fallback проверка
Если потоковое чтение не работает, клиент автоматически переключится на обычное чтение `response.text()`.

## Возможные проблемы

1. **CORS ошибки** - убедитесь что n8n настроен на разрешение CORS
2. **Таймауты** - проверьте `FETCH_TIMEOUT` в `fetchWithTimeout.ts`
3. **Неправильный формат** - убедитесь что n8n отправляет именно NDJSON
4. **Кодировка** - убедитесь в UTF-8 кодировке ответов
